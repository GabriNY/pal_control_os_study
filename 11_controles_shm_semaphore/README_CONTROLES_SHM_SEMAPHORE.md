# Etapa 11 - Controles simulados: Shared Memory + Semaphore

Estos controles siguen una dificultad progresiva y el estilo usado anteriormente en el repositorio.

## Orden sugerido

1. Control 01: Shared Memory servidor/cliente.
2. Control 02: Semaphore como exclusión mutua.
3. Control 03: Shared Memory + Semaphore con 5 procesos totales.
4. Control 04: orden estricto con un set de 5 semáforos.
5. Control 05: Signal + Semaphore + Shared Memory.
6. Control 06: fork + execv + Semaphore + Shared Memory.
7. Control 07: integración de IPC: Shared Memory + Semaphore + Message Queue.

Cada carpeta contiene:
- `ENUNCIADO.txt`
- `solucion/`
- `COMPILACION_Y_EJECUCION.txt`

Primero resuelve el ENUNCIADO sin mirar `solucion/`.
